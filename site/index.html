The Two-Second Decision Challenge

Who picked up?

An open benchmark for the first two seconds of an outbound call.

Explore results Run the benchmark

The problem

The same hello.
Two possible answers.

A person and a voicemail greeting can sound identical through the cutoff. When the available evidence can’t tell them apart, the agent can say it’s uncertain.

How it works

From audio to verdict.

  1. Replay the call

    Feed each detector the same authored audio and scripted call events.

  2. Commit or abstain

    Use the evidence available by 2,000 ms. Return uncertain when the evidence falls short.

  3. Score the decisions

    Measure how often each detector commits, how often it’s wrong, and when it decides.

Quickstart

Run it locally.

From the repository root, use Python 3.12 to replay the public challenge pack or reproduce the reserved evaluation.

Validate and replay

python -m whoanswered validate --pack fixtures/v1
python -m whoanswered replay --pack fixtures/v1 --out build/replay

Reproduce the comparison

python -m whoanswered compare --pack fixtures/v2/eval --policy-pack fixtures/v1 --out build/compare
cmp docs/v2-eval-comparison.json build/compare/comparison.json
