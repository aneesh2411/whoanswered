Who picked up?

WhoAnswered is the Two-Second Decision Challenge, an open benchmark for the first two seconds of an outbound call.

The problem

When an outbound call connects, the agent has to decide whether it reached a human, voicemail, a screener, or silence. An opening “hello” can sound identical for a human and voicemail. When the evidence is ambiguous, the agent can say it is uncertain.

How it works

A benchmark pack supplies authored audio and scripted call events. Replay feeds the same observations to deterministic detectors. Candidate settings are calibrated on the development split to decide when to commit or abstain.

Scoring treats uncertain as a valid abstention and tracks committed coverage and errors among commitments separately.

Honest limits

All audio is authored synthetic audio. Real phone audio is untested.

Quickstart

From the repository root, validate and replay the public challenge pack with Python 3.12.

python -m whoanswered validate --pack fixtures/v1
python -m whoanswered replay --pack fixtures/v1 --out build/replay

To reproduce the reserved evaluation comparison, run these commands.

python -m whoanswered compare --pack fixtures/v2/eval --policy-pack fixtures/v1 --out build/compare
cmp docs/v2-eval-comparison.json build/compare/comparison.json
